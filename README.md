# Visionary · 视觉创作工作台

用聊天的方式做视觉创作：描述想法、添加参考素材，让视觉创作助手帮你制作图片、视频，或先整理创意和分镜。你可以继续追问、调整方向、暂停任务，并在历史记录里找回之前的创作。

**第一次使用，先把网页打开，再按需连接真实模型。** 不需要会写代码，也不用分别启动前端和后端。

| 你想做什么 | 从这里开始 |
| --- | --- |
| 先看看界面和操作流程 | [启动并体验演示](#quick-start) |
| 生成真实图片或视频 | [连接真实创作能力](#connect) |
| 上传素材、继续修改、下载作品 | [完成第一次创作](#first-creation) |
| 启动失败、配置不生效、没有产物 | [常见问题](#faq) |
| 查配置文件、接口或参与开发 | [技术与进阶说明](docs/technical-reference.md) |

<a id="quick-start"></a>

## 1. 先把网页打开

### 第一步：安装 Node.js

Node.js 是运行这个工作台的软件，只需安装一次。

1. 打开 [Node.js 官网](https://nodejs.org/zh-cn/download)，下载适合自己电脑的 **LTS（长期支持）版本**，按安装向导完成安装。本项目要求 **Node.js 22 或更高版本**。
2. 安装后重新打开终端：macOS 打开「终端」，Windows 打开「PowerShell」或「终端」。终端就是下面输入命令的窗口。
3. 粘贴这条命令，按回车：

```bash
node -v
```

看到 `v22.x.x`、`v24.x.x` 等版本号，且最前面的数字不小于 `22`，就可以继续。如果提示找不到 `node`，先看[常见问题](#faq)。

### 第二步：进入项目文件夹

先准备好完整项目文件夹。如果从 GitHub 下载，可以点击 **Code → Download ZIP**，下载后解压。

确认文件夹内能看到 `server.js`、`package.json` 和本 README，然后按系统选择一种方法：

- **macOS**：在终端输入 `cd `（末尾保留一个空格），把项目文件夹拖进终端，再按回车。
- **Windows**：打开项目文件夹，在文件资源管理器地址栏输入 `powershell`，按回车。
- **已经在用 VS Code**：打开项目文件夹，选择菜单「终端 → 新建终端」。

### 第三步：启动

在刚才的终端粘贴：

```bash
node server.js
```

本项目没有第三方运行依赖，**不需要先运行 `npm install`**；第一次体验也不需要创建 `.env` 配置文件。

启动成功后，终端会显示类似：

```text
Visionary 视觉创作工作台：http://localhost:3000 · 演示模式
```

打开浏览器，访问 **[http://localhost:3000](http://localhost:3000)**。这是你自己电脑上的工作台地址，服务运行期间才能打开。

**使用时保持终端开启。** 停止本机服务时，在终端按 `Ctrl + C`，Mac 也是这个组合键。下次使用，进入同一项目文件夹，再运行 `node server.js` 即可。

> 如果已有正在执行的真实任务，先在网页点击「暂停」并等待确认，再停止本机服务。关闭网页或终端不等于暂停云端任务。

### 第四步：先发一句话试试

首次使用且尚未配置真实连接时，侧栏底部会显示「演示模式 · 未配置 Key」。在输入框粘贴下面的内容，按 **Enter** 发送：

```text
为一款香氛产品设计秋季主视觉，暖色自然光，背景简洁，画面比例 1:1。
```

看到标有「交互演示」的文字方案，就说明启动和基本操作正常。

**演示模式只返回本机预置的文字方案：不调用模型、不产生模型生成费用，也不生成真实图片或视频、不分析上传文件。** 它用于熟悉聊天、参数设置和历史记录。已经保存过真实连接的工作台会使用原配置；需要真实创作时继续下一节。

## 2. 连接真实创作能力

真实创作使用火山方舟的 **Seedance Managed Agent**，可以理解为在云端执行创作任务的助手。需要可用的方舟账号、相应模型权限和额度，实际调用会产生平台费用。

### 先准备最少的配置

打开 [火山方舟控制台](https://console.volcengine.com/ark/)，准备当前账号和项目下的 API Key，再从以下两种方式里选一种：

| 方式 | 需要准备 | 适合谁 |
| --- | --- | --- |
| 复用已有 Agent | **API Key + Agent ID** | 你或同事已经创建好视觉创作 Agent |
| 由工作台自动创建 Agent | **API Key + Agent 模型 ID + 图片模型 ID** | 没有现成 Agent，但已开通所需模型权限 |

API Key 是访问方舟服务的密钥；Agent ID 是现有创作助手的编号；模型 ID 是控制台提供的模型或接入点标识。**直接复制控制台里的值，不要用模型展示名称代替 ID。** 如果由同事协助配置，请让对方通过安全方式提供对应信息。

需要生成视频时，还要有可用的视频模型：复用已有 Agent 时确认其视频模型配置可用；自动创建时填写「视频模型」。模型是否可用，以账号权限和实际调用结果为准。

### 在网页里填写并保存

1. 点击侧栏底部的连接状态或齿轮图标，打开「连接设置」。
2. 在「**API 连接**」中，找到「API Key」，先将旁边的下拉选项改为「**替换密钥**」，再粘贴你的 Key。输入框默认锁定是正常的。
3. 核对「项目名称」。默认值为 `yingke`，请改成实际使用的项目；API 地址没有特别要求时保持默认。
4. 在「**模型与会话**」中，按上表选择的方式填写：复用时填「Agent ID」；自动创建时留空「Agent ID」，填写「Agent 模型」和「图片模型」。需要视频时一并核对或填写视频模型。「Environment ID」可以留空，首次真实创作时自动创建云端运行环境。
5. 点击「**保存设置**」，再点击「**测试已保存连接**」，根据页面结果检查连接。
6. 保存后，侧栏应显示「**Agent 配置就绪**」。关闭设置面板，点击「**新建创作**」，再发送需求。

**配置前创建的演示会话会继续使用演示模式，接好模型后请新建创作。** 网页设置保存后立即生效，重启后也会保留。

「Agent 配置就绪」表示必要字段已填齐；连接测试成功表示相关接口可以访问。模型权限、额度和生成效果，需要用一次实际创作确认。测试连接不会创建 Agent 或生成内容；首次真实创作可能创建并缓存云端 Agent 和运行环境。

> 这里需要的是支持方舟 Managed Agents 的服务。仅提供通用聊天接口（如 `/chat/completions`）的 Key 和地址，不能直接接入本工作台。

### 哪些字段可以先不填

| 设置项 | 什么时候需要 |
| --- | --- |
| 「素材库凭据」里的 AK / SK | 使用人像或私域素材库、将人物图片或视频入库时；普通文字和非人物参考素材创作可先留空 |
| Session Token | 使用临时 AK/SK 时；长期凭据通常留空 |
| 默认 AIGC 素材组 ID | 要指定已有素材组时；留空可自动创建或复用 |
| 真人认证回调地址 | 仅用于可选的旧版真人认证流程，日常上手可留空 |
| 高级设置里的其他字段 | 按实际需求调整，首次使用通常保持默认 |

API Key 和 AK/SK 是两套不同凭据，不能互相替代。使用人物素材时，先在「素材库凭据」里分别选择「替换密钥」并填写 AK/SK，核对同一项目下的素材权限；后续入库仍需通过平台审核。详细限制见[素材与人像说明](docs/technical-reference.md#素材与人像边界)。

## 3. 完成第一次创作

### 先生成一张简单图片

确认连接已保存，点击「新建创作」，将输入框下方的模式选为「**Agent**」。先不添加素材，发送：

```text
请生成一张香氛产品主视觉：琥珀色玻璃瓶放在木桌上，秋日暖阳从左侧照入，背景简洁，画面比例 1:1，不要文字。请交付可下载的图片。
```

你可以在「创作偏好」里调整画面比例、视觉风格等参数。等待回复，查看消息间的「执行过程」；如果出现工具确认，阅读具体内容后选择是否允许。

完成后，查看实际图片和产物卡片，点击文件链接打开或下载。**收到文字回复不一定代表已经生成图片或视频，以实际可查看、可下载的文件为准。** 云端下载链接可能过期，满意的作品请及时保存到电脑。

### 加入参考素材

图片、视频和音频可以拖入输入区，点击「＋」选择，或点击输入框后粘贴已复制的文件，支持多文件。文档请到「素材资产库」切换为「参考文档与素材」后上传，再点击「＋ 引用」。

支持 PDF、Word、TXT、Markdown，以及常用图片、视频和音频，**单个文件最大 512 MB**；人物素材入库另有格式和大小限制。

等待上传和同步完成后再发送。如果显示「本机保存 · 待配置 API Key」或同步失败，先完成连接配置，再点击「重试同步」或素材列表中的「同步到方舟」。仅保存在电脑上，还不能交给真实 Agent 使用。

视频和音频请复制或选择实际文件；粘贴网页地址会按文字处理。上传素材用于真实创作时会发送到方舟，请使用你有权使用且适合上传的内容。

### 在同一会话里继续修改

直接补充一句，例如：

```text
保留瓶子的构图，把背景改为深绿色，光线更柔和一些。
```

助手会沿用当前会话继续创作。已经在执行时，「排队发送」会等这一轮结束再处理，「立即引导」会把补充要求交给当前云端会话。

| 常用操作 | 使用方式 |
| --- | --- |
| 发送 / 换行 | `Enter` 发送，`Shift + Enter` 换行 |
| 暂停任务 | 点击「暂停」或按 `Esc`，等待云端确认 |
| 继续任务 | 在原会话点击继续，或按页面提示恢复会话 |
| 先讨论方案 | 在输入框下方选择「先制定计划」，或输入 `/plan`；此模式禁用执行工具 |
| 开始实际执行 | 切回「Agent」，或输入 `/agent` |
| 找回之前的创作 | 从侧栏会话或历史记录打开；刷新页面后记录仍在 |
| 查看更多操作 | 输入 `/`，打开命令菜单 |

刚上手时，用普通对话即可。需要助手持续推进同一个目标时，再了解[持久目标（Goal）](docs/technical-reference.md#持久目标)：它会自动续跑并持续消耗模型用量；可选的 Token 预算按轮次结束检查，当前轮次可能超出预算。

## 4. 常见问题

| 遇到的情况 | 怎么处理 |
| --- | --- |
| `node: command not found`，或提示「无法将 node 识别为……」 | 安装 Node.js 后关闭并重新打开终端，再运行 `node -v`；仍无效时重新安装，检查是否启用了加入 PATH 的选项 |
| 提示 `Cannot find module .../server.js` | 当前目录不对。重新进入能看到 `server.js` 的项目文件夹，再运行启动命令 |
| 提示「端口 3000 已被占用」或 `EADDRINUSE` | 先看是否已经开了一个工作台，尝试访问原地址；若要换端口，在 `.env` 设置 `PORT=3001` 后重新启动，改访问 `http://localhost:3001`。[如何创建 `.env`](docs/technical-reference.md#env-config) |
| 浏览器打不开页面 | 确认终端仍开着且没有启动错误；使用 `http://localhost:3000`，也可尝试 `http://127.0.0.1:3000`。如果改过端口，使用新端口 |
| 另一台电脑或手机打不开 | 当前版本仅允许本机访问。请使用启动服务的这台电脑上的浏览器 |
| 只出现文字方案，没有图片或视频 | 先看是否标有「演示模式」；接好模型后新建创作。真实会话还需使用 Agent 模式，明确要求生成文件，并确认对应模型权限 |
| 显示「Key 已配置 · 待配置 Agent」 | 仅填 Key 还不够。补充 Agent ID，或 Agent 模型和图片模型，保存后新建创作 |
| API Key 输入框不能输入 | 先将密钥字段的下拉选项改为「替换密钥」 |
| 测试连接成功，但生成失败 | 检查具体错误中的模型、项目权限、额度和素材审核信息；连接测试不验证全部生成权限 |
| 保存设置时提示任务或素材操作正在进行 | 先暂停创作并等待云端确认，以及当前素材操作结束，再保存 |
| 修改 `.env` 后没有变化 | 先重启服务；网页里保存的同名设置优先。如需改用 `.env`，在对应字段恢复环境配置并保存，见[配置优先级](docs/technical-reference.md#env-config) |
| 素材显示已保存在本机，但无法引用 | 参考素材要成功同步到方舟；人物资产要审核为 `Active`（可用）。按具体状态重试同步或查看审核错误 |
| 断网、刷新或重启后，不确定任务是否已提交 | 先打开原会话，按提示恢复并核实记录；不要连续重发相同需求，以免重复计费。恢复失败时可用任务的 `sessionId` 到方舟控制台核实 |
| 任务结束，但产物没有出现或链接过期 | 在原任务的「创作交付」区域点击「刷新产物」。它只查询和更新已有产物，不重新生成；纯文字任务可以没有文件 |

遇到表格以外的问题，可以记录报错文字、`node -v` 的结果和操作步骤，方便排查。分享截图或日志前，遮住 API Key、AK/SK 等密钥。

## 5. 数据保存与进阶使用

会话记录、目标、素材和网页设置默认保存在项目的 `data/` 文件夹，重启后仍保留；原始上传文件保存在 `data/uploads/`。需要备份或换电脑时，先暂停任务、停止服务，再备份 `.env`（如有）和整个 `data/`。其中可能包含密钥和私人素材，请妥善保管。

生成作品仍需单独下载保存；本机记录不等于云端生成文件的永久备份。删除本机会话或素材只会删除本机文件或记录，云端 Session、Files 和 Assets 需要到方舟另行管理。

当前项目面向本机个人使用。若要正式部署或供多人使用，请先阅读[接入与部署边界](docs/technical-reference.md#接入真实视觉-agent)，配置自己的存储、网络、登录和访问控制。

需要进一步配置或参与开发时，可直接查阅：

- [配置文件与环境变量](docs/technical-reference.md#env-config)：自定义端口、数据目录、模型和密钥。
- [会话、发送与恢复](docs/technical-reference.md#会话发送与恢复)：排队、立即引导、暂停、重连和命令。
- [图片与视频水印](docs/technical-reference.md#图片与视频水印)：无可见水印要求、实际验收、视频提示词和任务 ID。
- [素材与人像规则](docs/technical-reference.md#素材与人像边界)：人物入库、私域素材库、可选真人认证与回调页。
- [会话 API](docs/technical-reference.md#会话-api)、[本机 API](docs/technical-reference.md#本机-api)：程序接入与二次开发。
- [测试说明](docs/technical-reference.md#测试)：`npm test` 运行使用本机模拟接口的测试；浏览器测试另需 Playwright / Chromium。

项目的主要文件：

```text
├── server.js          启动入口，同时提供网页和后端服务
├── public/            网页界面
├── lib/               创作会话、模型连接、素材和设置逻辑
├── tests/             自动化测试
├── docs/              技术与进阶说明
├── .env.example       可选配置文件的模板
└── data/              首次启动时自动创建的本机数据目录
```
